TEK PAKET — RENDER + NEON
Developer: Veyrath
========================================

1. ZIP'i çıkart.
2. Bütün dosya/klasörleri GitHub repository köküne yükle.
3. Render servisi > Environment bölümünde DATABASE_URL değerini Neon Connect ekranından aldığın PostgreSQL bağlantı adresiyle ayarla.
4. Deploy et.
5. /admin/login üzerinden admin panelini aç.
6. Normal kullanıcı hesaplarını yalnızca Admin Paneli > Yeni Üyelik Oluştur üzerinden oluştur.
